第 1 题

已知 α ∈ R，sin α + 2cos α = (√10)/2，则 tan α = ______。

答案：tan α = 3 或 tan α = −1/3

第一步：先说明 cos α ≠ 0

若 cos α = 0，则 sin α = ±1，此时 sin α + 2cos α = ±1，

而 (√10)/2 ≈ 1.58 ≠ ±1，矛盾，所以 cos α ≠ 0。

第二步：两边平方，化为齐次式

(sin α + 2cos α)² = ( (√10)/2 )² = 5/2

sin²α + 4sin α cos α + 4cos²α = 5/2

两边同乘 2：

2sin²α + 8sin α cos α + 8cos²α = 5

把右边的 5 写成 5(sin²α + cos²α)：

2sin²α + 8sin α cos α + 8cos²α = 5sin²α + 5cos²α

移项整理得：

3sin²α − 8sin α cos α − 3cos²α = 0

第三步：同除 cos²α，解关于 tan α 的方程

因为 cos α ≠ 0，两边同除以 cos²α：

3tan²α − 8tan α − 3 = 0

因式分解：

(3tan α + 1)(tan α − 3) = 0

所以 tan α = −1/3 或 tan α = 3。

第四步：检验（平方可能产生增根）

当 tan α = 3 时，取 sin α = 3/√10，cos α = 1/√10， 则 sin α + 2cos α = 5/√10 = (√10)/2 ✔

当 tan α = −1/3 时，取 sin α = −1/√10，cos α = 3/√10， 则 sin α + 2cos α = 5/√10 = (√10)/2 ✔

两个值都符合原式，故 tan α = 3 或 −1/3。

另解：辅助角公式

sin α + 2cos α = √5 · sin(α + φ)，其中 tan φ = 2。

由 √5 sin(α + φ) = (√10)/2，得

sin(α + φ) = (√2)/2，

所以 tan(α + φ) = ±1，即

(tan α + 2) / (1 − 2tan α) = ±1

分别解得 tan α = −1/3 与 tan α = 3，结论相同。

第 2 题

已知 (sin α + 3cos α) / (3cos α − sin α) = 5， 则 cos²α + (1/2)sin 2α = ______。

答案：3/5

第一步：由已知条件求出 tan α

去分母（分母 3cos α − sin α ≠ 0）：

sin α + 3cos α = 5(3cos α − sin α)

sin α + 3cos α = 15cos α − 5sin α

6sin α = 12cos α

sin α = 2cos α

说明：若 cos α = 0，则 sin α = ±1，左边 = sin α / (−sin α) = −1 ≠ 5，矛盾， 所以 cos α ≠ 0，两边可同除 cos α，得

tan α = 2

第二步：化简所求式子

由二倍角公式 sin 2α = 2sin α cos α，得 (1/2)sin 2α = sin α cos α，于是

cos²α + (1/2)sin 2α = cos²α + sin α cos α

提取 cos²α：

= cos²α (1 + tan α)

第三步：由 tan α 求 cos²α

利用 1 + tan²α = 1 / cos²α：

cos²α = 1 / (1 + tan²α) = 1 / (1 + 2²) = 1/5

第四步：代入求值

原式 = (1/5) × (1 + 2) = 3/5

所以 cos²α + (1/2)sin 2α = 3/5。

小结

“已知 sin α 与 cos α 的一次齐次式（或分式）的值，求 tan α”是常见套路： 把条件化为 sin α = k·cos α 即可得 tan α；求值时把式子统一化成含 tan α 与 cos²α 的形式， 再用 cos²α = 1/(1 + tan²α) 计算。
